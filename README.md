# 🥬 Manav E-Ticaret Uygulaması

Modern teknolojilerle geliştirilmiş, kullanıcıların online olarak manav ürünlerini görüntüleyip sipariş verebildiği full-stack bir e-ticaret uygulamasıdır.

---
## 🚀 Özellikler

- 🛒 Sepet yönetimi (ürün ekleme / çıkarma)
- 📦 Sipariş oluşturma ve sipariş geçmişi görüntüleme
- 🧾 Sipariş detayları (ürünler, adet, fiyat, toplam)
- 🚚 Teslimat veya mağazadan teslim seçeneği
- 📞 Müşteri bilgileri ve adres yönetimi
- 🖼️ Ürün görselleri (Next.js Image optimizasyonu)
- ⚡ Server Components & API Routes
- 🎨 Responsive ve modern UI (Tailwind CSS)

---

## 🛠️ Kullanılan Teknolojiler

### Frontend
- **Next.js 14 (App Router)**
- **React**
- **TypeScript**
- **Tailwind CSS**
- **React Icons**

### Backend
- **Next.js API Routes**
- **MongoDB**
- **Mongoose**
